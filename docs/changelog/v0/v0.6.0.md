# v0.6.0 — 2026-08-07

Milestone 13, and with it **spec 03 is complete**: the composable table pipeline
(`tablePipeline` on `egl-utils-js/table`) and the bridge that drives it from the DOM
(`bindTableControls` on `egl-utils-js/dom`). One owner of the row set derives one memoized
view through a fixed order, so **filtering and sorting compose instead of discarding each
other** — the defect this wave existed to remove.

The contract is [`docs/specs/03_spec_dom_ui_table.md`](../../specs/03_spec_dom_ui_table.md)
(F42 and F51 land here, completing F42–F51). Three ADRs record the decisions:
[ADR-0034](../../adr/0034-one-owner-one-derivation-and-the-pipeline-budget.md),
[ADR-0035](../../adr/0035-the-controls-bridge-and-the-dom-budget.md), and
[ADR-0036](../../adr/0036-collecting-every-benchmark-and-the-collapse-floor.md).

Purely additive: nothing in the v0.1.0–v0.5.0 surface changed behaviour, the root entry is
untouched, and there is still no runtime dependency and no new peer.

### Added

- **`tablePipeline(options)`** on `egl-utils-js/table` (ROADMAP 13.1, spec 03 F42) — one
  owner of a row set, deriving one memoized view through a fixed
  `filters → search → sort → paginate` order.

  **Composition is the point.** The shape this replaces keeps a filterer and a sorter side by
  side, each holding its own copy of the original rows: applying one discards the other, so a
  user who sorts a filtered table watches their filter vanish. Here there is a single owner
  and a single derivation, so a sort applies *to the filtered set* and a filter applies *to
  the sorted order* without either component knowing the other exists.

  **Commands are transactions.** Every command emits exactly one `'change'` carrying the
  derived view, even when it changes two things — `setFilter` also resets to page 1, and that
  is one event, not two. `batch()` collapses several commands into one. Subscribers therefore
  never observe a half-applied state, which is what makes a renderer a pure function of the
  view.

  **The observer surface is composed, not inherited.** `on`/`once`/`off` delegate to an
  internal `EventEmitter` whose `emit` stays private, so no consumer can publish a `'change'`
  the pipeline did not derive. Per-listener exception isolation comes along from
  [ADR-0006](../../adr/0006-typed-event-emitter-contract.md) rather than being reimplemented.

  **Pure and DOM-free**, so the same instance derives page 1 on a server and hydrates in the
  browser. `view()` is memoized on a state version, so reading it twice with no intervening
  command costs nothing — asserted by object identity rather than by timing, where it cannot
  flake.

- **`bindTableControls(pipeline, bindings, options)`** on `egl-utils-js/dom` (ROADMAP 13.2,
  spec 03 F51) — the bridge from filter inputs, a search box, sort headers, pagination and a
  page-size select to a pipeline's public commands, reflecting the derived view back.

  **It speaks only the public API.** The binding calls commands and listens to `'change'`; it
  never reaches into pipeline state. That is what keeps the pipeline server-usable and the
  binding replaceable.

  **Filter inputs are deliberately one-way.** The binding writes the pipeline, never the
  input, so a re-render cannot fight a user mid-keystroke — the classic two-way-binding
  cursor jump cannot occur.

  **One delegated sort listener** on the header row survives every re-render of the rows, and
  each header carries `aria-sort` reflecting the actual derived order, so assistive
  technology reads the state rather than the intent. Pagination controls take their enabled
  state from the view, and the status text comes from an injectable `formatStatus` whose
  default assumes no language (`'1 / 4'`).

  **Teardown is structural.** The returned unbind, or an aborted `AbortSignal`, detaches
  every listener, cancels every pending debounce, and unsubscribes from the pipeline — so no
  trailing debounce can fire into a torn-down page. Row rendering stays the caller's, wired
  with `delegate` in the caller's own `'change'` handler.

### Changed

- The **benchmark gate now collects every benchmark** (ROADMAP 13.3,
  [ADR-0036](../../adr/0036-collecting-every-benchmark-and-the-collapse-floor.md)). Its
  report classifier discarded any group it could not pair with a baseline library, so all ten
  absolute benchmarks — `validateEmail`, `parseDuration`, `urlSearchParams`, `uuid`, the two
  type guards and the four pipeline cases — ran on every CI benchmark job and were then
  thrown away; the recorded baseline held 13 entries where it should have held 23. A
  regression in `validateEmail`'s linear cost or in the pipeline's derivation could not have
  been caught by anything.

  Silence was the defect, not the pairing rule, so the fix is structural: classification is
  now a pure, unit-tested function that is **total** — every benchmark is either classified
  or named, and the gate refuses to proceed *or to record* while any problem stands. A naming
  mistake fails the run instead of shrinking the gate.

  Absolute figures are held to a **collapse floor** (4x slower than recorded fails) enforced
  only within a matching environment tag, and their millisecond figures are printed on every
  run. **No library code changed.**

- Spec 03's **NFR-12 budget clauses moved twice more**, each in the PR that measured it:
  `/table` from an indicative 3 kB to **3.5 kB** (ADR-0034) and `/dom` from 4 kB to **5 kB**
  (ADR-0035) — the latter because F51 pulls the `debounce` its own teardown contract depends
  on. Both are the ADR-0015 pattern: measure, trim what is genuinely fat, then amend the
  clause rather than delete a contract obligation to protect an estimate.
- Spec 03's **NFR-13 clause was extended** to say the derivation figure is collected and
  reported in milliseconds, and its **NFR-04 non-extension clause clarified**: the nightly
  gate gains an absolute floor, which is not a parity claim against a third party but does
  grow what the gate enforces.
- Spec 03's **F51 gained a `formatStatus` option** while being implemented, because a default
  that embeds a human-readable string is policy, not mechanism — the frozen clause lacked the
  seam and was amended in the same PR.

### Fixed

- **Browser smoke: the table-delegation case now clicks a cell rather than the row**
  ([BUG-0001](../../bugs/2026/08/BUG-0001-webkit-row-click-intercepted.md)). Aiming at the
  `<tr>` made the test depend on a hit-test the standard does not pin down: the CI WebKit
  build resolved the row's centre point to the ancestor `<table>`, which Playwright refuses
  to click through, so the case exhausted a 30 s timeout and left the `browser` gate red from
  ROADMAP 13.2 onward. Clicking a cell also models what a real user does. **No library
  behaviour was affected** — delegation worked in every engine throughout, which the same
  test's first click always proved.

### Notes

- **NFR-13 finally has the measurement its clause specifies.** The budget reads "≤ 50 ms *on
  the CI runner*", and until 13.3 only workstation figures existed. Recorded on the runner:
  **10.24 ms mean, 11.96 ms p99** — 4.9x headroom, with a 1.03x three-run spread.
- That recording corrected two documented assumptions. The M13 benchmark report predicted a
  hosted runner would be *slower* than the development workstation, and ADR-0036 first
  assumed it would be *noisier*. It is neither: **~2x faster and an order of magnitude more
  stable** (spread 1.01x–1.10x across all eleven absolute benchmarks, against 1.05x–1.68x
  locally). Corrections landed where the claims were made.
- Sizes: `/table` **3273 B** against its amended 3.5 kB clause, `{tablePipeline}` **3250 B**;
  `/dom` **4718 B** against its amended 5 kB clause, `{bindTableControls}` **2093 B**. A
  composing facade measures about the same as its whole entry — 23 B apart here — which is
  why spec 03 exempts facades from the per-function 1 kB clause.
- **1290 tests at 100% line and branch coverage** across every source file, and the browser
  suite now loads `/table` and `/dom` in all three engines: **90/90** green, including the
  focus save/blur/restore scenario spec 03 §6 owed from M12.
- Milestones 1–13 are complete. The next wave (spec 04, M14–M16) is the opt-in
  `egl-utils-js/bootstrap` toolkit, built on these entries rather than replacing them.
