# v0.8.0 — 2026-08-09

Milestone 15: **`bsTable`**, the toolkit's flagship — a complete Bootstrap 5 table over the
framework-agnostic `tablePipeline`, which it keeps **public**. The facade is a shortcut you
can step out of, not a ceiling: `.pipeline` *is* the composed instance, and an application
that already holds one passes it in and keeps it.

The contract is [`docs/specs/04_spec_bootstrap_toolkit.md`](../../specs/04_spec_bootstrap_toolkit.md)
(F66–F67; F52–F65 shipped in v0.7.0, F68–F81 follow). Two ADRs record the decisions:
[ADR-0039](../../adr/0039-a-facade-with-a-door-and-what-the-table-costs.md) and
[ADR-0040](../../adr/0040-one-grammar-one-pager-and-a-ceiling-below-its-own-parts.md).

Purely additive for existing consumers: nothing in the v0.1.0–v0.7.0 surface changed
behaviour, the root entry is untouched, and the package still declares **zero runtime
dependencies**. `bsTable` needs no `bootstrap` peer — it renders markup and class names,
and the peer belongs to the behaviour wrappers that follow.

### Added

- `bsTable` grows a `controls` option (ROADMAP 15.2, spec 04 F67, ADR-0040): a per-column
  filter row, a global search box, a page-size select and an F65 pagination bar, wired to
  the table's pipeline through F51 `bindTableControls` — public commands only, debounced
  inputs, `aria-sort` on sortable headers, and one structural teardown. Every
  human-readable string is injectable and none is rendered unasked: the status text is
  digits, page sizes are digits, and an unpaginated option appears only if you name it.
  The rendered nodes are exposed as `table.controls`.
- `tablePipeline` accepts `operators` (spec 03 F42, amended): the F33 custom-token
  vocabulary, now applied to every filter string the pipeline compiles — a column filter
  and the global search alike. Previously only `locale` was forwarded, so a project's own
  operators were unreachable from any string filter.

- `bsTable` on `egl-utils-js/bootstrap` (ROADMAP 15.1, spec 04 F66, ADR-0039): a complete
  Bootstrap 5 table rendered from column descriptors over an F42 `tablePipeline` that stays
  **public** as `.pipeline` — filter, sort and page compose, commands re-render, and an
  existing pipeline can be passed in and is borrowed rather than adopted. Cells obey the
  builder escape contract per column, row activation is one delegated listener and works
  from the keyboard, and a non-primitive cell value without a `format` throws instead of
  being stringified into the page.
### Notes

One measurement worth publishing, because it settles the design claim rather than
decorating it: F67's controls added **3518 B** against **3499 B** of parts the clause
already named — the pipeline, the F51 bindings and the F65 pager. Nineteen bytes of glue.
A facade that composes is the size of what it composes, which is why
[ADR-0040](../../adr/0040-one-grammar-one-pager-and-a-ceiling-below-its-own-parts.md)
raised the `bsTable` ceiling from a figure that had been set below the sum of its own
parts before a single cell was rendered.
