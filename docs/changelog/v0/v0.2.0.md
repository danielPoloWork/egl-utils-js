# v0.2.0 — 2026-08-06

Milestone 9 of the second capability wave: three new Node-safe subpath entries (`/text`,
`/net`, `/table`) and four additions to the root and `/storage` surfaces, delivered under
the same quality bar as v0.1.0 — 100% line and branch coverage across 857 tests, enforced
per-entry and per-function bundle budgets, tree-shakeability proved per import, and still
zero runtime dependencies.

The design contract for the wave is
[`docs/specs/02_spec_core_extensions.md`](../../specs/02_spec_core_extensions.md)
(F26–F39 land here; F40–F41, the `/logging` subpath, follow in v0.3.0). Seven ADRs —
0019 through 0025 — record the decisions.

### Added

- New `egl-utils-js/text` entry (ROADMAP 9.1, spec 02 F26-F28): `truncate`, `wrapText`, and
  `fixedWidth` — pure string-shaping helpers that measure in UTF-16 code units and never emit a
  lone surrogate ([ADR-0019](../../adr/0019-subpath-family-and-code-unit-text-semantics.md)).
  `fixedWidth` returns exactly the requested width for any input, `truncate` counts its marker
  inside the budget and is idempotent, and `wrapText` preserves paragraph breaks while
  collapsing whitespace runs. ADR-0019 also fixes the wave's subpath policy: capability groups
  get their own Node-safe entries rather than root exports, so the frozen 6 kB root ceiling is
  never renegotiated to make room for optional code.
- New `egl-utils-js/net` entry (ROADMAP 9.2, spec 02 F29-F32): `isIpv4`, `parseIpv4`,
  `formatIpv4`, `ipv4ToKey`, `ipv4FromKey`, and `subnetMaskFromPrefix`
  ([ADR-0020](../../adr/0020-strict-ipv4-parsing-and-the-sortable-key-codec.md)). Parsing is
  strict — four decimal octets, no leading zeros, none of the legacy `inet_aton` shorthand,
  octal, hex, or bare-integer forms that different parsers resolve differently — so a
  validity check and the parse that follows it can never disagree, which is the divergence
  behind allowlist-bypass and SSRF bugs. The key codec renders three zero-padded digits per
  octet, making lexicographic order match numeric address order and octet-aligned network
  containment a `startsWith`. Invalid content returns `null`; only a wrong argument type throws.
- New `egl-utils-js/table` entry (ROADMAP 9.3, spec 02 F33-F35): `compileFilter`,
  `comparator`, and `paginate` — the query primitives behind a data table, pure and
  Node-safe so they run server-side too. `compileFilter` interprets a small filter grammar
  (substring, `=`, `!=`, `^prefix`, `suffix$`, `>` `>=` `<` `<=`, and the nesting
  `null`/`empty`/`blank` sentinels) that is **total**: every string compiles, including a
  half-typed one, so a filter box can compile on every keystroke — and **no `RegExp` is
  ever built from user input**, so a hostile expression cannot cost more than its length
  ([ADR-0021](../../adr/0021-filter-expression-grammar.md)). Custom operators plug in
  through `options.operators` rather than forking the grammar. `comparator` returns a
  genuine total order in every mode — blanks pinned to one end regardless of direction,
  mixed types ordered by type then value (so sorting stays transitive on real data),
  `Intl.Collator` for text, locale opt-in for numbers
  ([ADR-0022](../../adr/0022-comparator-total-order-semantics.md)). `paginate` clamps an
  out-of-range page instead of failing.
- `formatDuration` and `normalizeError` on the root entry (ROADMAP 9.4, spec 02 F36-F37,
  [ADR-0023](../../adr/0023-duration-round-trip-and-the-error-record.md)). `formatDuration`
  is the exact inverse of `parseDuration` — same ADR-0009 grammar, so
  `parseDuration(formatDuration(ms)) === ms` for every whole second, with sub-second
  remainders truncated to a `'0s'` floor and fractional input accepted so `measure()`'s
  output can be handed straight over. `normalizeError` turns anything a `catch` block can
  receive — an `Error`, a string, a response object, `null`, a symbol, a value whose getters
  throw — into one record `{ name, message, stack?, code?, status?, detail?, cause }`, never
  throwing, with `cause` holding the original by identity so the error can still be rethrown.
- `pageSessionId` on `egl-utils-js/storage` (ROADMAP 9.5, spec 02 F39,
  [ADR-0024](../../adr/0024-page-session-id-scope-and-budget.md)): a v4 UUID held under
  `sessionStorage` semantics, so it survives reloads and in-tab navigation, dies with the
  tab, and differs between tabs — the scope needed to correlate logs and telemetry within
  one browsing session. It is a **correlation id, not a credential**: unauthenticated and
  readable by any script on the page. Where storage is unavailable or blocked it falls back
  to memory (stable for the realm) and never throws, because a diagnostics helper must not
  be what breaks a page.
- `createResource` on the root entry (ROADMAP 9.6, spec 02 F38,
  [ADR-0025](../../adr/0025-resource-repository-over-an-injected-client.md)): a REST
  resource factory returning `{ list, get, create, update, patch, remove }` over a
  **client passed as a parameter, never imported** — anything exposing
  `get`/`post`/`put`/`patch`/`delete` works, so it costs 505 B rather than inheriting the
  1304 B `httpClient` facade, and a test needs no network and no mocking framework. Ids are
  encoded as exactly one path segment (an id containing `/` or `..` can never widen the
  path) and a `null`/`undefined` id throws rather than requesting `…/undefined`; per-call
  `signal`/`timeout`/`headers` pass straight through.

### Changed

- **`egl-utils-js/storage` grew from 1706 B to 2027 B** on a full-entry import, because
  `pageSessionId` reuses `uuid` rather than reimplementing entropy handling (ADR-0008
  centralizes that decision deliberately). Importing only the three original wrappers now
  costs **1698 B — slightly less than before** — so the cost falls solely on consumers of
  the new function, and that scenario is pinned as its own permanent size-limit row. The
  spec 01 NFR-01 `/storage` clause is amended from 2 kB to 2.1 kB accordingly
  ([ADR-0024](../../adr/0024-page-session-id-scope-and-budget.md)).
- The root full import grew from 5104 B to **5806 B** with F36–F38, still inside the frozen
  6 kB NFR-01 ceiling, and its budget row is now tightened to that measurement — the
  spec-02 root surface is complete.
- A shared `crypto` chunk now exists in `dist/`, since both the root entry and `/storage`
  import it. It is what stops the crypto code being emitted twice; `publint`,
  `arethetypeswrong`, `agadoo`, and every per-function budget row pass with it.

### Fixed

- `release.yml` never read `docs/releases/v<X.Y.Z>.md`, so the hand-written release notes that
  step 3 of the release process mandates were produced and then ignored — the v0.1.0 draft came
  out as a bare 61-entry auto-generated PR list. The workflow now passes the file as the release
  body (the generated list is appended below it) and **fails if it is absent**, so the prose
  cannot be skipped silently.
