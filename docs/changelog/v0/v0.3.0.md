# v0.3.0 — 2026-08-06

Milestone 10, and with it **spec 02 is complete**: every requirement F26–F41 is delivered.
One new Node-safe entry — `egl-utils-js/logging` — closes the wave that v0.2.0 opened,
under the same bar as its predecessors: 100% line and branch coverage across 948 tests
(91 of them new), enforced per-entry and per-function bundle budgets, tree-shakeability
proved per import, and still zero runtime dependencies.

The design contract is
[`docs/specs/02_spec_core_extensions.md`](../../specs/02_spec_core_extensions.md)
(F40–F41 land here; F26–F39 shipped in v0.2.0), and
[ADR-0027](../../adr/0027-logging-formatter-sink-split.md) records the decisions.

Also in this release, though invisible to consumers: the supply-chain gate now runs with
**zero audit exceptions** ([ADR-0026](../../adr/0026-brace-expansion-override-replaces-the-audit-exception.md)).

### Added

- New `egl-utils-js/logging` entry (ROADMAP 10.1, spec 02 F40-F41): `logger`,
  `formatLogLine`, `formatTimestamp`, and `LOG_LEVELS`
  ([ADR-0027](../../adr/0027-logging-formatter-sink-split.md)). The requirement reads like
  one line of output, but four decisions hide inside it, and each is a reason hand-rolled
  loggers become unpleasant to live with:
  - **Verbosity is one ordered threshold**, not a boolean per severity. Eleven flags admit
    2048 states, most of them nonsense ("errors off, trace on") and none orderable; a
    threshold expresses every sensible configuration and no other. `'silent'` is a
    threshold value, and a call below the floor returns before the clock is read, the id
    resolved, or a record allocated.
  - **Destination and line shape are separate axes.** A sink is `(record, format) => void`:
    a text sink calls the formatter, a structured transport ignores it and never pays to
    build a string it would discard. Both sink styles are first-class rather than one being
    the awkward case.
  - **Context is explicit.** `child('db')` names a child `'parent.db'` from a string the
    author wrote, so log lines survive minification — deriving names from `this` or
    `fn.name` reads better at the call site and then fails silently in production only,
    corrupting every line at once.
  - **Logging never throws into application code.** A logger is called from `catch` blocks,
    so a dead sink, throwing clock, throwing id function, hostile `toString`, or throwing
    formatter costs that one record and is reported once through `console.error` — it can
    never replace the error being recorded. If `console.error` is itself missing or
    throwing, the failure is dropped rather than escalated.

  Every seam is injectable with a working default (`sink`, `format`, `now`, `id`), which is
  what makes the logger testable with a two-line capturing sink and a frozen clock instead
  of a `console` spy, and usable outside a browser.

  **CR and LF are collapsed to a single space in the message *and* in the `name` and `id`
  columns** — one step beyond what F41 first required, because an id arrives from an
  injected function and is no more trusted than the message. One record therefore renders
  as exactly one line for every possible input, so attacker-controlled text cannot forge a
  second log entry (log injection). A fast-check property asserts it over arbitrary
  strings, and the browser suite re-checks it in all three engines.

  Sizes (min+brotli): the entry is **1390 B** against its 1.6 kB clause; `formatLogLine`
  alone is **876 B**, `formatTimestamp` **301 B**, and `LOG_LEVELS` **60 B**. `logger`
  measures 1361 B and takes a documented 1.45 kB NFR-08 exception — importing the factory
  imports the subsystem it composes, the same argument
  [ADR-0015](../../adr/0015-final-size-budgets-and-the-httpclient-exception.md) accepted
  for `httpClient`. The 60 B figure is the informative one: composition is what costs, not
  the entry.

### Changed

- Timestamps render in **local time** by design (`formatTimestamp` accepts a `Date` or epoch
  milliseconds): these lines are read by a human next to the process that wrote them. A
  consumer needing UTC or ISO-8601 injects a `format`, or reads `record.ts`, which is plain
  epoch milliseconds. Recorded in ADR-0027 so the constraint is discoverable rather than
  surprising.

### Security

- The `pnpm audit --audit-level high` gate runs with **zero exceptions**
  ([ADR-0026](../../adr/0026-brace-expansion-override-replaces-the-audit-exception.md)). A
  new high advisory in a dev-only path
  ([GHSA-rgw5-rvv9-x895](https://github.com/advisories/GHSA-rgw5-rvv9-x895),
  `brace-expansion` DoS, patched in 5.0.9) is fixed by a **range-scoped** pnpm override
  that lifts only the vulnerable v5 instance, leaving the v1/v2 consumers whose export
  shape broke an earlier unscoped attempt untouched. With it in place no `brace-expansion`
  advisory remains at any severity, so the legacy `ignoreGhsas` entry — now a stale
  suppression — is retired rather than extended, and ADR-0016 §6's "it cannot be fixed
  here" finding is superseded. **No published bytes change:** dev dependencies never reach
  a consumer (NFR-06; `files` publishes `dist` plus the two shim sources).
- The threat model gains a **Log records** trust boundary with a full STRIDE pass: log
  injection under Spoofing, the "the trail is the asset" argument for containment under
  Repudiation, and an explicit **no redaction** claim under Information disclosure — the
  library adds no destination of its own and deciding what may be logged stays with the
  caller.

### Notes

- No change to any previously released surface: F1–F39, `VERSION`, and the `/text`, `/net`,
  `/table`, `/storage`, `/sanitize`, `/errors` entries are untouched.
- The catalogue gains **Strategy** (sink and formatter) and **Facade** (logger) rows, plus
  its **first Rejected row**: Singleton, considered for a module-level default logger and
  rejected because module-scope mutable state is the dual-package hazard spec 01 §4 forbids
  and would make tests order-dependent.
