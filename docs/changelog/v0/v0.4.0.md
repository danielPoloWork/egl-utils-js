# v0.4.0 — 2026-08-06

Milestone 11, and the first half of spec 03: a new browser-leaning entry,
**`egl-utils-js/dom`**, with ten exports covering element binding, event delegation, native
setters, HTML fragment injection, textarea auto-grow, and URL parameter merging. Delivered
under the same bar as its predecessors: 1100 tests at 100% line and branch coverage, enforced
per-entry and per-function bundle budgets, tree-shakeability proved per import, and still zero
runtime dependencies.

The design contract is
[`docs/specs/03_spec_dom_ui_table.md`](../../specs/03_spec_dom_ui_table.md) (F43–F48 land
here; F42 and F49–F51 — the table pipeline and the UI components — follow in M12 and M13).
Three ADRs record the decisions: [ADR-0028](../../adr/0028-dom-entry-fails-fast-and-the-floor-gate-sees-the-dom.md),
[ADR-0029](../../adr/0029-delegation-teardown-and-setter-symmetry.md),
[ADR-0030](../../adr/0030-sanitize-is-a-required-parameter.md).

Every export in this release is **additive**: nothing in the v0.1.0–v0.3.0 surface changed
behaviour, and the root entry is untouched — its frozen 6 kB ceiling was neither spent nor
renegotiated.

### Added

- **New `egl-utils-js/dom` entry** (ROADMAP 11.1–11.3, spec 03 F43–F48). Browser-leaning by
  contract, and the first entry in the library that cannot work without a browser — so it had
  to answer a question the previous nine never faced: what happens when the environment is
  absent?

  **It fails fast rather than degrading.** With no DOM present, an export that needs the
  ambient document throws `DomContractError` (code `EGL_DOM_CONTRACT`) naming the API, the
  contract, and `egl-utils-js/table` as the DOM-free alternative. The storage wrappers' silent
  in-memory fallback ([ADR-0010](../../adr/0010-storage-in-memory-fallback-contract.md)) was
  right because a degraded store still keeps a value; a `setVisible` that quietly does nothing
  **reports success while the page stays unchanged**, and is indistinguishable from a hydration
  bug. Importing the entry is always safe — the document is resolved per call, never at module
  scope — so a server render fails on *use*, not on import. An export handed an explicit
  element or root needs no ambient document at all, which keeps these usable inside a
  server-side DOM implementation.

  - `bindElements(map, {root, strict})` → `{elements, missing}`. Resolves a whole
    `{name: selector}` markup contract in one pass and **reports what is missing**. Binding one
    element at a time turns a selector typo into a `null` that travels and resurfaces as
    *"cannot read properties of null"* far from its cause; `missing` makes the startup check one
    assertion, and `strict: true` refuses to boot instead. The returned `elements` object is a
    snapshot, not a live view — which is the honest argument for why delegation exists.
  - `delegate(root, type, selector, handler, {signal, capture})` — attaches **one** listener
    that serves every current and future descendant matching `selector`, so a re-render needs
    no rebinding and there is no teardown pass to forget. The handler receives the **matched**
    element, not `event.target` (the deeper node actually clicked — an icon inside a button, a
    `<span>` inside a row), and matching is bounded by `root` because `closest` otherwise
    climbs to the document. Teardown is an internal `AbortController`: unsubscribe is one
    `abort()`, **idempotent by construction**, with no retained handler reference; a caller
    `signal` is bridged so it cleans up in both directions.
  - `setEnabled` / `setVisible` / `setValue` — **no-ops on nullish**, because an absent optional
    element is a normal state and requiring `if (el)` at every call site is how those guards get
    forgotten; a wrong *type* still throws. `setVisible` drives the `hidden` attribute, or a
    given class **instead** — never both, so hide and show always undo each other (the common
    hand-rolled pair that clears two mechanisms and sets one leaves an element stuck).
    `setValue` covers text, textarea, checkbox, radio and single/multiple selects, clears on
    nullish rather than writing `"null"`, leaves no phantom selection when no option matches,
    and **dispatches no event** — a plain assignment fires none either, and synthesising one
    could re-enter the handler that called it.
  - `injectFragment(target, url, {sanitize, position, fetch, signal, headers})` — **`sanitize`
    is required and has no default.** Both candidates were wrong: sanitizing by default would
    make `/dom` depend on the DOMPurify *optional* peer that
    [ADR-0012](../../adr/0012-sanitize-default-profile.md) confined to `/sanitize`; not
    sanitizing by default would make the dangerous choice the quiet one. So the decision is the
    caller's and it is recorded at the call site — pass a sanitizer, or the literal `false` to
    state the source is trusted. Errors **propagate**: a non-2xx rejects with `HttpError`
    carrying status and body, so a shell assembled from several fragments can be told apart
    from a partial one. `'beforeend'`/`'afterbegin'` use `insertAdjacentHTML`, so existing
    nodes and their listeners survive where `innerHTML +=` would destroy them.
  - `autoGrow(textarea, {maxRows, measure, signal})` — releases the inline height **before**
    measuring, which is what lets a textarea shrink as well as grow (reading `scrollHeight`
    while a height is set measures that height). Layout is read through an injectable `measure`
    seam, so the behaviour is verifiable where no layout exists and `getComputedStyle` stays
    optional rather than structural. Detach restores the original inline styles exactly.
  - `withUrlParams(url, params)` — merges parameters through `URLSearchParams` over a
    hand-split URL, so a second `?` is **impossible** and a relative URL works
    (`new URL('/a?b=1')` throws without a base). Pure and SSR-safe; fragments preserved;
    arrays repeat the key; nullish values skipped, matching `urlSearchParams` (F17).
  - `isElement` and `requireDocument` are exported too — structural type checks rather than
    `instanceof`, so a node from an iframe or a second realm passes where a cross-realm
    `instanceof Element` fails.

- **`DomContractError`** on `egl-utils-js/errors` (code `EGL_DOM_CONTRACT`), carrying `missing`
  for the strict-mode binding failure.

### Changed

- Spec 03's **NFR-14 is amended** (in 11.2) to the contract the implementation actually has:
  an export that resolves the *ambient* document throws when there is none, while an export
  handed an explicit node needs no global document. The original clause said *every* `/dom`
  export throws — which 11.1 had already diverged from, deliberately and with a test. Found by
  writing the next item against the spec, not by a failing gate.

### Security

- **The platform-API floor gate now sees the DOM**
  ([ADR-0028](../../adr/0028-dom-entry-fails-fast-and-the-floor-gate-sees-the-dom.md), spec 03
  NFR-16). [ADR-0017](../../adr/0017-platform-api-floor-gate.md) promised *deny-by-default*
  coverage, but the scanner matched only `Global.member` and `Global(` over a policed list
  containing **no DOM type at all** — so `x instanceof Element` and every `globalThis.document`
  read passed in silence. Starting a DOM wave under that gate would have left it weakest
  exactly where it matters most. The policed list gains the DOM surface, two precise reference
  shapes are recognised (`instanceof <Global>` and `globalThis.<Global>`), and a `GLOBALS` entry
  no longer blanket-authorizes the members reached off it.

  The extension immediately surfaced **eight real, undeclared dependencies** — `globalThis`
  reads of `crypto`, `document`, `fetch`, `localStorage`, `location` and `sessionStorage`
  across five modules, all long-standing, all properly guarded, none declared. The inventory
  grew from 21 to 29 entries across the milestone, almost none of it new code. It is verified
  non-vacuous by planting an un-inventoried DOM use and observing the failure, and it has since
  caught two more real declarations (`addEventListener`'s `{signal}` option, `getComputedStyle`)
  before they could ship undeclared.

- The threat model gains two trust boundaries with full STRIDE passes: **HTML fragments**
  (the XSS path, the propagate-don't-swallow argument, URL-passed-as-given, and an explicit
  note that the library performs **no sanitizing of its own** — it routes markup through
  whatever the caller supplied) and, from v0.3.0, **Log records**.

### Notes

- `/dom` measures **2100 B** for the whole entry against a 4 kB clause; every plain function is
  inside its 1 kB budget (`injectFragment` 595 B, `autoGrow` 542 B, `delegate` 392 B,
  `setValue` 299 B, `withUrlParams` 276 B, `setVisible` 256 B, `requireDocument` 252 B,
  `setEnabled` 201 B, `bindElements` 616 B, `isElement` 61 B).
- `/errors` moves 310 B → 340 B (measured 317 B): `DomContractError` costs 26 B, paid by
  everyone importing the taxonomy.
- No new runtime dependency and no new peer: the sanitizer reaches `injectFragment` as a
  **parameter**, so `/dom` never imports `/sanitize`.
