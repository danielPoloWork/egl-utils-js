# egl-utils-js v0.1.0

The first public release: universal JavaScript async, data, and event utilities for
Node.js (>= 18) and modern browsers, with **zero runtime dependencies** in the root entry.

```bash
npm install egl-utils-js
```

## What's in it

The complete 25-function surface from the frozen specification, across four entry points:

| Entry | Contents |
|---|---|
| `egl-utils-js` | async combinators, data helpers, validation, typed events, web, crypto, diagnostics |
| `egl-utils-js/storage` | `localStorageWrapper`, `sessionStorageWrapper`, `cookieHelper` |
| `egl-utils-js/sanitize` | `sanitizeHtml` + `defaultSanitizeProfile` (DOMPurify as an optional peer) |
| `egl-utils-js/errors` | `EglError` and seven typed subclasses |

**Signal-first cancellation.** Every async combinator (`delay`, `timeout`, `retry`,
`parallelLimit`, `asyncQueue`) accepts an `AbortSignal` and rejects with a typed
`AbortError` — never a silently hung promise.

**Typed errors with stable codes.** One `EglError` base, one frozen `EGL_*` code per
subtype. Identity is checked via `.code`, never cross-realm `instanceof`, so the
dual-package hazard cannot bite.

**Pure by default, stateful by contract.** The data and async modules never mutate their
inputs; `EventEmitter`, the storage wrappers, `cookieHelper`, and `httpClient` are
documented as stateful.

**Secure defaults where it matters.** `cookieHelper` writes `SameSite=Lax` + inferred
`Secure` and percent-encodes names and values, so a value can never inject an attribute.
`sanitizeHtml` ships a deny-by-default allowlist verified against a 46-payload
mXSS/bypass corpus. `uuid` and `hashString` use Web Crypto only — `Math.random` is never
a fallback.

## Supported platforms

Node.js >= 18 · Safari >= 15.4 · last two versions of Chrome, Firefox, and Edge ·
TypeScript >= 5.0. Published as dual ESM/CJS with types generated per format, so a CJS
consumer's types match its runtime module format.

## Known limitations

- The platform-API gate verifies API **availability**, not **behavioural** differences
  between engine versions. Catching those would need real old-Safari runs.
- `sanitizeHtml` does not sanitize CSS, rewrite URLs, or protect attribute-position
  templating — a Content Security Policy remains the right complement.
- Pre-1.0: the public surface is complete and gated, but not yet frozen under a stability
  contract. Breaking changes before 1.0.0 arrive as `MINOR` bumps.
