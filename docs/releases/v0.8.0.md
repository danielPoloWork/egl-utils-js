# egl-utils-js v0.8.0

**`bsTable`** — a complete Bootstrap 5 table rendered from column descriptors, over the
same `tablePipeline` the framework-agnostic entry already shipped. What makes it a facade
rather than a wrapper is the door: **`.pipeline` is the composed instance**, not a copy and
not a private field, so an application that outgrows the shortcut steps out of it without
rewriting its data flow.

```bash
npm install egl-utils-js
```

Purely additive: nothing in the v0.1.0–v0.7.0 surface changed behaviour, the root entry is
untouched, and the package still declares **zero runtime dependencies**. `bsTable` needs no
`bootstrap` peer — it emits markup and class names; you supply Bootstrap's CSS.

## What's new

| Entry | Added |
|---|---|
| `egl-utils-js/bootstrap` | `bsTable`, with an optional `controls` band |
| `egl-utils-js/table` | `tablePipeline` accepts `operators` — the custom filter vocabulary, now reaching every string filter it compiles |

### A table, and the pipeline stays yours

```js
import { bsTable, bsBadge } from 'egl-utils-js/bootstrap';

const table = bsTable(container, {
  columns: [
    { key: 'host', label: 'Host', sortable: true, filterable: true },
    { key: 'ip', label: 'Address', sortable: true, align: 'end' },
    // A value that is not a primitive needs a format — the library never picks a date
    // format, or stringifies an object, on your behalf:
    { key: 'seen', label: 'Last seen', type: 'date', format: (v) => v.toLocaleString('it') },
    // A node needs no markup decision at all:
    { key: 'up', label: 'State', format: (v) => bsBadge(v ? 'up' : 'down', {
      variant: v ? 'success' : 'danger',
    }) },
  ],
  data: hosts,
  pageSize: 25,
  striped: true,
  hover: true,
  responsive: true,
  rowKey: 'id',
  empty: 'No hosts match these filters.',
  onRowClick: (row) => open(row.id),   // one delegated listener, and Enter/Space work
});

// The same F42 instance the /table entry exposes — commands re-render the table:
table.pipeline.setFilter('ip', '^192.168');
table.pipeline.toggleSort('seen');
table.setData(await refresh());
```

Filter, sort and page **compose** — applying one never discards the other — because the
derivation belongs to the pipeline, not to the table. Already hold a pipeline (a
server-derived first page, one shared with a chart)? Pass it in: it is **borrowed**, and
`destroy()` unsubscribes without tearing it down.

### Controls, and nothing English rendered unasked

```js
const table = bsTable(container, {
  columns,
  data: hosts,
  controls: {
    filterRow: true,   // one box per filterable column, speaking the filter grammar
    search: true,      // over the columns marked `searchable`
    pageSize: true,    // digits; add `{ allLabel: 'All' }` for an unpaginated choice
    pagination: true,  // a numbered bar, plus a status element
    toolbar: myButtons,
  },
});

table.controls.search.focus();   // the rendered nodes are yours too
```

Every human-readable string is injectable, and the defaults render **digits rather than a
language**: the status text is `'1 / 4'`, page sizes are numbers, and an "all" option
exists only if you supply its word. Accessible names do default to English — a name has to
be words — and each takes a `label`.

Custom filter operators belong to the pipeline, so a filter box speaks them without knowing
they exist:

```js
const pipeline = tablePipeline({
  source: hosts,
  columns,
  operators: { '~': (suffix) => (value) => String(value).endsWith(suffix) },
});
bsTable(container, { columns, pipeline, controls: { filterRow: true } });
// typing `~01` in a filter box now matches gw-01 and srv-01
```

### Cells that refuse to guess

A cell value that is neither primitive, nullish, nor a node throws a `TypeError` naming the
column rather than being stringified into the page — `[object Object]` in a table is a
defect that ships. Markup is **per column**: `{ html, sanitize }` on one column opens that
column alone, so enriching a status cell cannot open the eleven beside it.

## Under the hood

One measurement worth publishing, because it settles the design claim rather than
decorating it: the controls added **3518 B** against **3499 B** of parts already named in
the budget — the pipeline, the DOM bindings and the pager. **Nineteen bytes of glue.** A
facade that composes is the size of what it composes.

2109 tests on Node 18/20/22, 100% line coverage, real-engine scenarios in Chromium,
